# Gisel Studio de Belleza

Web estática de Gisel Studio de Belleza.

## Estructura
- `index.html`: página principal tipo link-in-bio.
- `styles.css`: estilos de la página principal.
- `assets/`: logo y favicons.
- `landings/catalogo-servicios.html`: catálogo informativo.
- `landings/combos-promos.html`: combos y promociones.
- `landings/styles.css`: estilos de las páginas internas.
- `landings/config.js`: configuración de WhatsApp y enlaces internos de las landings.

## Publicación
El sitio puede publicarse directamente como sitio estático en GitHub Pages o copiarse al hosting.
